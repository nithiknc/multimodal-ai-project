

\# Multimodal AI Image Question Answering



\## Project Overview

A multimodal AI application that accepts an image and a text question and generates an answer using a pretrained Vision-Language Model.



\## Technologies

\- Python

\- Flask

\- Hugging Face Transformers

\- BLIP VQA

\- PyTorch

\- Git and GitHub



\## Features

\- Image upload

\- Text-based questions

\- AI-generated answers

\- Flask web interface

\- Visual Question Answering



\## Installation



1\. Clone the repository.

2\. Create a virtual environment.

3\. Install dependencies.

4\. Run the Flask application.



```bash

python -m venv venv

venv\\Scripts\\activate

pip install -r requirements.txt

python app.py

```



5\. Open http://127.0.0.1:5000



\## Model

Salesforce/blip-vqa-base



The pretrained model is downloaded by Transformers on its first use.



\## Project Purpose

Created as an academic project to explore multimodal AI, version control and software development practices.
